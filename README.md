# Property Management System

## Overview
A Property Management System developed using Python, MySQL, and Power BI to manage property listings, bookings, owners, and analytics.

## Features
- Add, update, delete, and view properties
- Owner and booking management
- User authentication system
- MySQL database integration
- City-wise property price analysis
- Interactive Power BI dashboards
- Business insights and analytics

## Technologies Used
- Python
- MySQL
- Power BI
- SQL
- Git & GitHub

## Dashboard Insights
- Average property prices by city
- Property type distribution
- Booking analytics
- Business performance tracking

## Project Status
Completed and deployed on GitHub.
